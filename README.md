# Wave_Qi_String Theory

#### 介绍
波气弦理论（WQS）是以“气”为本原的统一拓扑物理框架。宇宙包含波、气、弦三种基础形态：波为一维动态曲线，气为二维拓扑曲面，弦为三维凝聚实体，三者存在六种内在转化关系。粒子、场与物理常数是三者在不同边界条件下拓扑耦合演化的涌现结果。理论以旋影方程、倒弦方程为核心，引入咬尾系数q描述相位内禀不对称；质量、电荷为真空拓扑守恒拆分单元，力求从第一性原理对微观现象提供自洽拓扑解释。
